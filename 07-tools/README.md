# 🛠️ AI Engineering Tech Stack

A curated list of tools and frameworks that I use to build, evaluate, and scale AI-driven applications.

---

## 🧠 Orchestration & Development
- LangChain / LangGraph: For building complex, stateful agentic workflows.
- LlamaIndex: The go-to framework for advanced RAG and data indexing.
- Haystack: Highly modular framework for building search and RAG pipelines.

## 📊 Data & Vector Databases
- Vector DBs: Qdrant, Weaviate, or pgvector (PostgreSQL) for semantic storage.
- Graph DBs: Neo4j for managing complex relationships in data.
- Data Parsing: Unstructured.io or LlamaParse for handling messy PDFs and documents.

## 🚀 Serving & Deployment
- vLLM: High-throughput serving engine for LLMs.
- Triton Inference Server: For multi-model, multi-framework serving.
- Ollama: For local development and testing of open-source models.

## 🧪 Evaluation & Monitoring
- Ragas / Arize Phoenix: For measuring RAG performance (Faithfulness, Relevance).
- Weights & Biases (W&B): For tracking experiments and model training.
- Prometheus/Grafana:* For infrastructure and latency monitoring.
